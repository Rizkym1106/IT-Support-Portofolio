# IT Support Portfolio — Practical Documentation

Dokumentasi portofolio praktis IT Support yang mencakup instalasi sistem operasi, troubleshooting jaringan tingkat pengguna (*end-user network troubleshooting*), serta konfigurasi dan penanganan masalah perangkat cetak (*printer*).

Repository ini dibuat untuk membuktikan kemampuan teknis, metodologi pemecahan masalah (*troubleshooting*), dan standar dokumentasi kerja di lingkungan IT Support / Helpdesk.
