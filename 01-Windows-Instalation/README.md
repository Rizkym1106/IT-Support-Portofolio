# Project 01 — Windows Installation & Configuration

## 📌 Deskripsi Proyek
Proyek ini bertujuan untuk membuktikan kemampuan teknis dalam melakukan instalasi ulang sistem operasi Windows, konfigurasi boot priority pada BIOS/UEFI, hingga pemeriksaan status perangkat hardware setelah instalasi selesai.

---

## 🎯 Tujuan Praktik
* Mempersiapkan media instalasi Windows secara aman.
* Menyesuaikan konfigurasi Boot Priority pada lingkungan BIOS/UEFI.
* Melakukan instalasi ulang sistem operasi Windows.
* Melakukan konfigurasi dasar dan verifikasi fungsionalitas hardware pasca-instalasi.

## 📝 Ringkasan Langkah Praktik
1. **Persiapan Media**: Menyiapkan installer Windows dan memastikan backup data penting.
2. **Konfigurasi BIOS/UEFI**: Masuk ke menu BIOS/UEFI dan mengatur *Boot Priority* ke USB installer.
3. **Proses Instalasi**: Menjalankan wizard instalasi Windows hingga masuk ke lingkungan desktop.
4. **Pemeriksaan Driver & Device Manager**: Memastikan driver hardware terinstal dengan benar tanpa eror (*yellow exclamation mark*).
5. **Pengujian Fungsi**: Memeriksa kelayakan fungsi dasar komputer (audio, display, jaringan, dan input device).

> **Catatan Keselamatan**: Selalu pastikan data telah ter-backup sebelum melakukan format atau instalasi ulang sistem operasi.
